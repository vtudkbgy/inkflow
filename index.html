            Règles

            Petit : total de 4 à 10. Grand : total de 11 à 17. Ces deux paris perdent sur un triple. Total : tu vises un total précis, payé même sur un triple. Triple : les trois dés montrent la même face.

            Les jetons débloquent des personnalisations (achat définitif) et des fournitures mises en stock.

            Ton compte

            Ton code client permet au banquier de t’envoyer des jetons, un prêt ou un retrait à toi seul.

            -----

              Code du banquier

              Un code cadeau crédite le solde. Un code de prêt crédite le solde et ajoute la même somme à ta dette.

              Chaque code ne sert qu’une fois sur cet appareil : sans serveur, l’usage est mémorisé localement.

              Le banquier peut aussi t’envoyer des jetons avec ton code client : un bouton « Récupérer » apparaît alors en haut de cette page (connexion Internet nécessaire pour le recevoir).
